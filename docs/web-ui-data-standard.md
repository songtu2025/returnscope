# 退货语义分析智能体 Web 数据展示规范

本文件是 `docs/web-ui-standard.md` 的专项扩展。任务涉及表格、列表、数据状态、数据格式、图标、图片或图表时必须读取。

## 1. 表格与列表

- 文本左对齐，数字、数量和比例右对齐，状态可居中；同类列在全站保持一致。
- 表头只表达字段含义和单位，筛选条件和长说明放在筛选区或帮助内容中。
- 表头高度使用现有 `40px`，普通记录使用 `44px`，包含摘要、状态和操作的业务记录可使用 `80px`。
- 操作列放在末尾并保持稳定；高频操作直接展示，低频操作收纳到菜单。
- 排序、筛选、分页、选中和刷新状态必须可见，返回列表时尽量恢复用户上下文。
- 批量操作显示已选数量、作用范围和不可处理项；跨页选择必须明确是否包含未显示记录。
- 可增长数据默认分页；只有数据量小且边界确定时才一次展示全部。
- 宽表格只能在自身容器横向滚动，按业务需要固定任务名、记录标识或操作列。

## 2. 数据页面状态

每个数据页面按能力覆盖：

1. 首次加载。
2. 正常数据。
3. 尚无数据，并提供创建、导入或启动任务的下一步。
4. 筛选无结果，并提供清除筛选的下一步。
5. 请求失败，并保留条件和重试入口。
6. 无权限，不显示敏感数据或伪造空状态。
7. 数据处理中、部分完成、已归档或版本冲突等业务状态。

局部刷新不得阻塞无关区域；加载占位、错误区域和正常内容应保持尺寸稳定，避免页面跳动。

## 3. 数据格式

- 后端系统时间戳使用 UTC；前端尚未形成统一时区转换策略，不得默认按浏览器本地时区或其他未确认时区转换。
- 业务源日期保留源数据的日期、粒度和业务口径；纯日期字段不得因时区转换发生日期偏移。
- 涉及跨时区展示时，实施前必须明确目标时区、转换边界、夏令时处理和显示格式，并在界面中标明必要的时区信息。
- 整数使用千位分隔；比例统一小数位；金额显示币种并按业务精度格式化。
- 空值统一显示 `--`，不得混用空字符串、`null`、`N/A` 和模糊文案。
- 枚举和任务状态显示统一中文业务文案，不直接展示后端原始代码。
- 文件大小、行数、记录数、版本号和置信度必须带清晰单位或字段名。
- 长编号、任务 ID、哈希和版本标识允许截断展示，但必须提供完整值的查看或复制方式。

## 4. 语义分析数据

- 分类结果必须能回溯数据版本、分类标准版本、模型配置快照、源记录和证据原文。
- 问题标签、正面标签、主因、部位、置信度、质量状态和复核状态必须分栏或分组表达，不能混成不可解析的长文本。
- 证据原文保持原意并与标签对应；高亮不能改变文本，缺少证据时明确显示“无文本证据”。
- 自动结果、人工修改和发布版本必须可区分，并显示操作者、时间、原因和版本关系。
- 置信度只作为辅助信息，不能用颜色或分数替代质量状态、证据和人工复核结论。
- 共享任务和复核记录对普通用户遵循同一展示规则；管理员标识只用于解释受限操作，不改变业务结果含义。

## 5. 图标与图表

- 业务图标统一使用 Phosphor Icons，不用 Emoji 或手绘 SVG 代替常见操作图标。
- 图标尺寸目前由各页面按上下文设置，尚无统一图标尺寸令牌；修改时优先参照同类控件，并验证尺寸稳定和可访问名称。
- 不熟悉的图标必须配文字或提示，图标不能单独承担复杂含义。
- 业务图表统一使用 Recharts，不增加第二套可视化库。
- 图表必须有标题、指标定义、单位、时间范围、图例和数据来源；颜色之外还要使用标签、线型或形状区分类别。
- 关键结果不能只存在于图表中，必须同时提供数值、摘要、表格或可访问替代信息。
- 图表加载、空数据、失败、数据不足和部分数据必须分别表达，不能渲染成误导性的零值图。
- 数据密集型业务页面不使用无业务价值的装饰图、人物插画或大面积背景图。

## 6. 数据安全与操作

- 默认只展示完成当前任务所需字段，订单号、客户信息、凭据和内部路径不得因调试进入界面。
- 下载和导出必须说明数据范围、筛选条件、版本和生成时间；无权限时后端拒绝并返回明确状态。
- 删除、归档、发布和存储清理不得仅凭前端状态推断成功，必须以服务端确认结果更新界面。

## 7. 数据验收

- [ ] 排序、筛选、分页、选中、刷新和返回状态行为明确。
- [ ] 加载、正常、空数据、筛选无结果、失败、无权限和业务状态按页面能力覆盖。
- [ ] 业务源日期保持源数据口径；系统时间戳的展示时区已经明确且没有执行未经确认的转换。
- [ ] 数字、比例、空值、枚举、版本和长标识格式一致。
- [ ] 分类结果能够追溯源数据、证据、配置、版本和人工修改记录。
- [ ] 图标只使用 Phosphor Icons，图表只使用 Recharts，关键数据有文本替代。
- [ ] 宽数据仅在容器内滚动，目标视口和缩放下关键列与操作可达。
