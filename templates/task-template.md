## Web 界面影响

- 是否涉及界面：是 / 否。
- 设计来源：无 / Figma / 截图 / 现有相似页面 / 其他。
- 目标视口：继承 `docs/web-ui-standard.md`；本任务存在例外时填写具体差异。
- 额外页面状态：继承 `docs/web-ui-standard.md`；本任务存在特殊业务状态时填写，不重复默认状态清单。
- 是否需要移动端：否；如需要，必须明确目标视口和布局要求。

涉及界面时，应附上设计稿、截图或相似页面位置。没有视觉来源时，Codex 必须先复用项目界面规范和已有页面，不得自行创造新的视觉方向。

## Codex 执行要求

请先阅读根目录和相关目录中的 `AGENTS.md`、README、需求文档、相关代码和测试。

非简单任务第一阶段暂时不要修改代码，请先输出：

1. 对需求和验收标准的复述。
2. 相关调用链和现有实现。
3. 计划修改的文件及内容。
4. 数据库、权限、配置、依赖和部署影响。
5. 潜在风险。
6. 测试和验证方案。
7. 涉及界面时，说明复用的设计令牌、基础组件、页面状态和目标视口。

方案明确并获得确认后，再按照最小修改原则实施。简单且边界明确，并且不涉及数据库、认证、权限、配置、依赖或部署的任务，可以直接实施并在完成后报告。
