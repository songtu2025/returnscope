# 用户反馈语义分析智能体 Web 布局与导航规范

本文件是 `docs/web-ui-standard.md` 的专项扩展。任务涉及页面骨架、桌面适配、应用壳层、登录页、导航或页面标题时必须读取。

## 1. 页面骨架

业务页面按以下顺序组织：

```text
固定侧栏 + 顶部栏
└── 页面主体
    ├── 页头：标题、必要说明、主操作
    ├── 状态或关键指标
    ├── 筛选、搜索和批量操作
    ├── 数据、表单或任务工作区
    └── 分页、结果说明或提交操作
```

- 页面主体使用 `--desktop-page-padding: 24px`，一级区块默认间距为 `16px`。
- 页面只保留一个一级标题；面包屑只在真实层级复杂且能帮助返回时使用。
- 数据密集页使用 `--layout-wide-max: 1680px`，长流程使用 `--layout-workflow-max: 1560px`，阅读或窄表单使用 `--layout-narrow-max: 1180px`。
- 只有内容具有独立边界、状态或操作范围时使用卡片，不把整页分区包装成层层嵌套的卡片。
- 长流程优先使用完整可用宽度和高度；高频操作保持可见，但固定区域不得遮挡内容。

## 2. 应用壳层

- 桌面壳层沿用 `236px` 固定深色侧栏和 `68px` 粘性顶部栏，页面工作区位于第二列。
- 侧栏承载 SEEKWAY 品牌、一级导航、系统入口和运行状态；顶部栏承载全局搜索、容量或任务状态、当前用户和退出入口。
- 页面级筛选和批量操作放在页面主体，不放入顶部栏。
- 当前一级导航使用现有绿色高亮和左侧强调线；任一时刻只能有一个当前项。
- 侧栏、顶部栏和浮层层级必须保持稳定，键盘焦点不能被粘性区域遮挡。

## 3. 桌面适配

- 交付范围从 `1024px` 宽开始，不新增移动端菜单、底部导航或触摸端专用流程。
- `1024px` 至 `1279px` 时，优先让多列指标、筛选和详情区域按业务分组换行；不得隐藏关键操作或压缩到文字重叠。
- 空间不足时表单从多列变为单列，工具栏允许换行，标签和控件不得覆盖。
- 页面主体不得出现意外横向滚动。宽表格、长列队或对比矩阵确有需要时，只允许其自身容器横向滚动，并提供可见滚动提示。
- 浏览器 `125%`、`150%` 和页面 `200%` 缩放时，关键流程仍须可通过纵向或局部容器滚动完成。
- 小于 `1024px` 不是交付视口，但窗口缩小时不得出现脚本错误或导致数据丢失。

## 4. 导航与页面标题

- 导航使用稳定的业务名词，按业务频率和流程排序，不按代码模块命名。
- 当前项、展开项、悬停项和焦点项必须可区分；图标导航始终保留可访问名称和可见提示。
- 页面标题描述当前对象或任务，例如“分析任务”“人工复核”“分类结果”，不使用“欢迎使用”等营销文案。
- 返回操作回到用户可预期的位置，并尽量保留列表筛选、分页、选中项和滚动位置。
- 全局搜索打开后应支持键盘操作和关闭，关闭后焦点返回触发按钮。

## 5. 登录与空壳状态

- 登录页沿用当前项目的简洁认证表单和绿色视觉，不接入规范仓库的通用登录模板，不为登录页迁移组件库。
- 登录错误留在表单内并关联输入；提交期间阻止重复请求，认证成功后进入用户原本要访问的可用页面。
- 应用初始化和会话校验期间使用稳定的加载壳层，不能先闪现无权限页面或管理员操作。

## 6. 布局验收

- [ ] `1024 x 640`、`1280 x 720`、`1440 x 900`、`1920 x 1080` 已逐一检查。
- [ ] `125%`、`150%` 浏览器缩放和 `200%` 页面缩放下关键操作可达。
- [ ] 侧栏、顶部栏、标题、筛选区、主内容和操作区没有遮挡或跳动。
- [ ] 页面级无意外横向滚动；必要横向滚动被限制在数据容器内。
- [ ] 返回、导航、全局搜索和登录流程可使用键盘完成并正确恢复焦点。
